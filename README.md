# Ficha de Pré-Atendimento — Dr. Carlos Augusto Damasceno

Página de pré-consulta em neurologia. O paciente (ou um acompanhante) preenche pelo
celular; ao concluir, o resumo clínico estruturado é enviado por e-mail ao Dr. Carlos,
com PDF anexo. O paciente vê apenas a confirmação.

No ar em: https://drcarlosaugusto.clinicablues.com.br

## Arquivos

- `index.html` — a página
- `ficha.js` — perguntas, geração do resumo e envio
- `config.js` — configuração (endpoint do robô, dados do consultório)
- `CNAME` — domínio personalizado do GitHub Pages (não apagar)

O robô que envia o e-mail (Google Apps Script) roda na conta do próprio Dr. Carlos.
A documentação completa fica na pasta interna da clínica.
